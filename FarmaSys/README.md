
# FarmaSys

## Sistema de Gestión de Farmacia

FarmaSys es un sistema de escritorio desarrollado
en Python para gestionar las operaciones de una
farmacia.

## Tecnologías utilizadas

- Python
- Programación Orientada a Objetos
- PySide6
- SQLite

## Funcionalidades principales

- Registro de medicamentos
- Gestión de inventario y lotes
- Control de fechas de vencimiento
- Registro de ventas
- Gestión de clientes
- Historial de ventas
- Generación de tickets internos
- Dashboard con estadísticas
- Reportes de ventas e inventario
- Alertas de stock y vencimiento

## Instalación

Instalar las dependencias desde la carpeta FarmaSys:

python -m pip install -r requirements.txt

## Ejecución

Desde la carpeta FarmaSys:

python Codigo/main.py

## Pruebas

Desde la carpeta Codigo:

python -m unittest discover -s tests -p "test_*.py"

## Objetivo del proyecto

Desarrollar un sistema informático que permita
mejorar el registro, control y consulta de las
operaciones de una farmacia, aplicando los
principios de la Programación Orientada a Objetos.
